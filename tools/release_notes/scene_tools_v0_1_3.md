Humanoid設定のアバターで、ヒューマノイドボーンをSceneビューにカプセル表示できるようにしました。

- Display Child Namesの詳細設定（表示タブ）にある「ヒューマノイドボーン（カプセル）」で切り替えます。初期値はOFFです。
- Animatorに割り当てられたHumanoidボーンを、左は青・右は赤・中心は黄色で表示します。選択中のボーンは選択色で強調します。
- 「カプセル太さ」で、ボーン長に対する半径の比率を調整できます。目・顎は対象外です。
- Avatarを差し替えた場合は「参照キャッシュ更新」で再検出します。
