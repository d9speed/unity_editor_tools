# D9speed Prefab Color Variants

複数のPrefabから、マテリアルを置き換えた色違いのPrefab Variantを作成します。

[案内ページ](https://d9speed.github.io/Unity_Tools/)からVCC / ALCOMへ登録し、本パッケージを導入してください。Editor Core 0.1.1以降が必要です。

1. `D9speed > Tools > PrefabColorVariantMaker`を開きます。
2. 元のPrefabと、色違いごとの名前の後置詞を指定します。
3. マテリアルの置換先を設定します。フォルダと名前からの候補設定も利用できます。
4. 設定を確認して作成します。元Prefabと同じフォルダにVariantを保存し、既存ファイルへの上書き前には確認が表示されます。

SkinnedMeshRendererとMeshRendererのマテリアルを対象とします。Unity 2022.3.22f1、Editor専用。VRChat SDKは不要です。旧Assets版との同時導入は型やGUIDが重複するため避けてください。
