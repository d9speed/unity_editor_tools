# Skinned Mesh Tools 0.1.1 検証記録

- 日付: 2026-10-03
- Unity: 2022.3.22f1
- 検証先: 起動中の既存 `importtest_2` プロジェクト
- 新規Unityプロジェクトは作成していません。

## 原因と修正

Ramune_Base.fbxの顔メッシュ `Body` には737個のBlendShapeがありますが、未編集のRendererでは `m_BlendShapeWeights` が空でした。従来は保存プロパティが見つからない行を省略するため、17個の分類見出しだけが表示され、スライダーは0個になっていました。

保存値のない行も0として表示し、実際の編集時だけ配列を補います。拡張時に既存の値を保持し、追加要素を明示的に0へ初期化します。配列長・メッシュの変更時に一覧のバインドを更新し、直後のUndoで配列長が元に戻った場合も、未バインドの行を同期します。

## 実データでの表示確認

| Renderer | BlendShape数 | 分類数 | 修正後のスライダー数 | 閲覧前後の保存配列長 |
|---|---:|---:|---:|---:|
| 顔 Body | 737 | 17 | 720 | 0 → 0 |
| 体 Body2 | 111 | 5 | 106 | 112 → 112 |

分類見出し用のBlendShapeはスライダー数に含めません。FBX・Prefab・作業シーンの保存は行っていません。

## 操作検証

既存プロジェクト内の一時プレビューシーンへFBXをインスタンス化し、実際のUI Toolkitパネルに拡張Inspectorを接続して検証しました。一時オブジェクト、Inspector用UI、プレビューシーンは終了時に破棄しています。

26項目すべて成功:

- 720行の生成と、閲覧だけでは空の配列を変更しないこと。
- 初回編集で737要素を補い、編集対象以外の値を0に保つこと。
- Prefab overrideの記録、配列補完後の再バインドと継続編集。
- 初回編集・継続編集のUndo/Redoと表示値の同期。
- 空配列へUndoした後も全行が表示され、編集可能であること。
- 非0フィルター、検索、一致しない検索、検索解除。
- 長さ2・値12/37の配列で全行を表示し、末尾側の編集で既存値を維持すること。
- 追加要素へ末尾の非0値が複製されないこと。
- 編集直後のUndoで長さ2へ戻った場合も表示値を0へ同期すること。
- 顔メッシュから体メッシュへの差し替えで106行へ更新し、閲覧だけでは配列を補完しないこと。

コンパイルエラーは0件。プロジェクト既存の他ツール由来の警告5件（未使用フィールド、ColorKeyPostProcessの重複型）を確認しました。
