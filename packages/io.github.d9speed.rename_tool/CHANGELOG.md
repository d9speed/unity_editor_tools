# Changelog

## 0.1.1 - 2026-09-21

- Fluent 2の共通UIを適用し、画面・説明・メッセージを日本語化。
- 変更前後を同じ行に表示する一覧表と、行ごとの適用チェックを追加。
- 選択件数、正規表現のエラー、適用ボタンの有効状態を画面内で表示。
- Hierarchy選択モードではフォルダ欄を無効化。
- Editor Coreの必要バージョンを0.1.5以降へ更新。

## 0.1.0 - 2026-09-20

- Rename Toolを独立したEditor専用VPMパッケージとして公開。
- 共通フォント設定をEditor Core 0.1.1以降から取得。
