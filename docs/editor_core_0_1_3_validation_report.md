# Editor Core 0.1.3 検証記録

2026-09-21、Unity 2022.3.22f1の専用検証プロジェクトで確認しました。

サクラエディタ連携のメニュー・起動処理・AutoHotkeyとGrepスクリプトの設定欄を削除しました。共通フォントとPrefab変更マークの保存キーは維持しています。外部アプリや利用者のスクリプトは削除しません。

`tools/validation_project/Editor/core_utilities_checks.cs`を残る機能へ合わせ、8項目すべて成功しました。フルパス取得、コンポーネントコピー、Transform操作とUndo、参照を保つアセット複製、設定の保存、Editor専用アセンブリと設定メニューを確認しています。

削除直後の初回起動ではUnityの既存コンパイルキャッシュが削除済みファイルを参照する一時的なCS2001を記録しました。同じ起動中の再コンパイルで解消し、チェック実行は成功しました。再起動後も8項目が成功し、CS2001の再発がないことを確認しています。

全公開パッケージに対するメタファイル・GUID・マニフェスト検査を通過しています。0.1.3のZIPは29,259 bytes、SHA-256は`a90ca81982b62371b51b5ac19b2bfcb67f6c9e5d372a2454ec85461b5335f09d`です。

Fluent 2のUI変更はこの版には含めていません。検討結果は[適合性評価](fluent2_ui_toolkit_assessment.md)にまとめています。
