SceneビューでTransformの親子階層を線で表示できるようになりました。SkinnedMeshRendererによる表示対象の絞り込みを解除し、未使用・補助ボーンやメッシュのないTransformも確認できます。

- 詳細設定に「ボーン階層（親子線）」を追加。スフィアとは個別に切り替えできます。
- 2カラムの名前ラベルからTransform参照をインスペクターへ直接ドラッグできます。ドラッグ中は選択を維持します。
- 最大深度の初期値・リセット値を0（無制限）に変更。スフィアサイズの上限を1.0に統一しました。
- 現在の編集ステージを対象とし、非表示・非アクティブのオブジェクトは除外します。

更新前の最大深度の保存値は維持されます。必要に応じて、詳細設定の「最大深度」を0に変更してください。

Unity 2022.3.22f1でコンパイルと、対象検出・親子線の接続・深度制限・設定保存を含む14項目の自動検証が成功しています。インスペクターのTransform欄への受け入れは別途自動検証済みですが、ウィンドウ間の実マウス操作によるドラッグ完了は自動検証の対象外です。

VCC／ALCOMでリポジトリを再取得し、D9speed Scene Toolsを0.1.1へ更新してください。
