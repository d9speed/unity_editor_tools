# Changelog

## 0.1.2 - 2026-10-03

- BlendShapeの分類を折りたたみからタブ切り替えへ変更。リセットボタンの直下に横一列で表示。
- グループが多い場合は左右ボタン・横スクロールバー・ホイールで移動可能。
- タブと移動ボタンはUnity標準のToolbarコントロールを使用し、色やフォントを上書きせずEditorのLight/Darkテーマへ追従。
- 「すべて」タブ、選択タブの強調表示、セッション内の選択記憶を追加。検索・非0フィルターは選択中のタブへ適用。
- 最初の分類見出しより前にある項目もタブへ収録。VRChatのリップシンク項目を含む場合は「リップシンク」、それ以外は「その他」と表示。

## 0.1.1 - 2026-10-03

- ウェイトの保存配列が空またはメッシュのBlendShape数より短い場合に、分類の見出しだけ表示されてスライダーが欠ける問題を修正。
- 未保存のウェイトも0として表示し、実際に編集したときだけ保存配列を補完。既存の値を保持し、追加分は0で初期化。
- 初回編集・Undo/Redo・メッシュ差し替えで配列やメッシュが変わった場合に、BlendShape一覧のバインドを更新。

## 0.1.0 - 2026-09-20

- 既存ツールを独立したEditor専用VPMパッケージとして公開。
- 既存ソースのGUIDを維持。
