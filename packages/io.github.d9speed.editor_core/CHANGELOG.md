# Changelog

## 0.1.9 - 2026-09-26

- `D9speed/Tools/説明画像つき板ポリプレハブ作成(EditorOnly)` を追加。文章・TMPフォント・文字色・背景色・解像度を調整し、PNGとUnlitマテリアルを参照するEditorOnlyのQuadプレハブを保存。
- PNG単体の保存、文字欠落の検出、はみ出し警告、プレビューの再利用、共通UIのフォント・ライト／ダーク設定に対応。
- TMP連携をEditor専用の任意アセンブリへ分離。TMP未導入時もCoreの既存機能を維持。

## 0.1.8 - 2026-09-26

- Inspectorのロック／解除を切り替えるショートカットを追加。初期設定はCtrl+L（macOSはCmd+L）。UnityのShortcutsの `Custom/ShortCutEX/InspectorLock` から変更可能。
- フォーカス中、マウス下、開いているInspectorの順に対象を選び、1つだけ切り替え。Inspectorがない場合は何もしません。

## 0.1.7 - 2026-09-23

- Hierarchyの右クリックに「選択オブジェクト名をコピー」を追加。選択したオブジェクト名をカンマ区切りでクリップボードへコピー。

## 0.1.6 - 2026-09-21

- Transform Mirrorで左右の末尾名（_L/_R、.L/.R、小文字、.001形式の連番）を入れ替え、子階層も対称化。
- 最寄りのPrefabルートからDFS探索し、作成予定のオブジェクトとConstraint／PhysBoneの参照ペアを2ペインで事前表示。
- Unity／VRC Constraintの参照・オフセット、PhysBoneのRoot／Ignore／Collider参照・Endpoint／Limit、PhysBone Colliderと標準Colliderの設定に対応。
- VRC Constraintは複製側を停止し、配置・参照・オフセットを設定してからロック／有効状態を復元。
- 重複選択・親子選択を整理し、同名既存オブジェクトの上書きを防止。処理全体をUndo／Redo可能に。

## 0.1.5 - 2026-09-21

- Fluent 2の共通部品をテキスト欄・オブジェクト欄・折りたたみ・一覧表へ拡張。
- `EditorUiControls`に画面構築用の共通ヘルパーを追加。
- 比較結果の不足・追加・配置差にライト／ダーク対応の色トークンを追加。

## 0.1.4 - 2026-09-21

- Transform MirrorへFluent 2のトークン設計を取り入れ、ライト／ダーク対応のUI Toolkit画面を適用。
- 共通USSと`EditorUiTheme`を追加。初回の適用対象はTransform Mirror。
- 対象数、ドロップ先の案内、一覧クリア、空のときの実行無効化を追加。
- カスタム基準点の使用状態と座標欄の編集可否を連動し、UI再構築・スクリプト再読み込みで対象と設定を保持。
- ミラー複製、回転、BlendShapeコピーとUndoの処理は維持。

## 0.1.3 - 2026-09-21

- サクラエディタ連携のメニュー・起動処理と、AutoHotkey／Grepスクリプトの設定欄を削除。
- 共通フォントとPrefab変更マークの設定は維持。

## 0.1.2 - 2026-09-21

- Unity Utilityのフルパス・アニメーションパス・コンポーネント名コピー、階層検索、複数コンポーネントの貼り付けを統合。
- Transformリセット、ミラー複製、メインカメラの向き合わせ、Prefab変更マークを統合。
- アセット群の参照を保つ複製を統合し、既存コピーの上書き防止と元のライセンス表記を追加。
- フルパス取得をVPM／UPMパッケージ内の実体ファイルと複数選択に対応。
- `D9speed > Settings`から共通設定を開けるようにし、フォント・Prefab表示・外部エディタ連携を集約。
- サクラエディタ連携の個人用固定パスを除き、ローカル設定で指定できるように変更。

## 0.1.1

- アバター名の違いを除いたメッシュ名の対応付け処理を共通化。

- ヒューマノイド対応、階層パス、コンポーネントコピー、ファイル名の共通処理を追加。
- 公開ツール向けのフォント設定をPreferencesに追加。既定はUnity標準フォント。
- Scene Tools 0.1.0が利用する既存APIを維持。

## 0.1.0

- Scene Toolsで利用するEditorObjectHelperを独立したVPMパッケージへ収録。
- 既存の型名、アセンブリ名、ソースと.metaを維持。
