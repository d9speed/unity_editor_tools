FBXからExtractした既存マテリアルにSubstance Painterの画像を一括設定する `D9speed/Tools/liltoonマテリアルセットアップ` を追加しました。マテリアル名とテクスチャの末尾名で照合し、プレビューから対象を選択できます。

AOMap・Roughness・MatCapマスクなどのsRGBをオフにし、Normal map設定とRoughnessからSmoothnessへの変換にも対応します。任意の雛形、重複候補の検出、マテリアル参照の維持、適用前の状態への復元を備えています。lilToonは別途導入してください。

公開済み0.1.13からの更新には、0.1.14で行った説明画像ツールのSprite PNG保存への整理も含みます。マテリアル・板ポリプレハブの自動生成は行わなくなりました。

Unity 2022.3.22f1 / lilToon 2.4.1で74項目の検証に成功し、lilToon未導入環境のコンパイルも確認しました。
