# Skinned Mesh Tools 0.1.2 タブ表示の検証

2026-10-03、Unity 2022.3.22f1の既存 `importtest_2` プロジェクトで確認しました。新規Unityプロジェクトは作成していません。

## 変更

分類ごとのFoldoutを、リセットボタン直下の横一列のタブへ置き換えました。選択タブだけのスライダーを生成し、「すべて」では全グループを表示します。選択をUnityセッション内で記憶します。タブと左右ボタンはUnity標準の `ToolbarToggle` / `ToolbarButton` を使い、色・文字色・フォントを上書きしません。

タブがInspectorの幅を超える場合は、左右ボタン・横スクロールバー・ホイールで移動できます。検索と非0フィルターは選択タブへ適用し、リセットは従来どおり全BlendShapeを対象とします。

見出し前の項目も保持します。Ramuneでは18個の項目を「リップシンク」へ収録し、17個の見出し由来の分類と「すべて」を合わせて19個のタブになります。

## 検証結果

既存のプレビューシーン検証をタブ表示へ合わせて更新し、以下の合計52項目が成功しました。作業中のアバターを検証対象として編集・保存していません。

- 既存の26項目: 空配列・短い配列の表示と初回編集、既存値保持、Prefab override、Undo/Redo、検索・非0フィルター、メッシュ差し替え。
- 新規26項目: 19タブの生成、リセット直下の配置、グループFoldoutの廃止、リップシンク18行・BROW36行・MMD46行・全720行の切り替え、選択の強調と再表示時の復元。
- 色・フォントのインライン指定がないことと、選択中のタブを再クリックしても1つのタブを選択し続けること。
- フィルターで0件になってもタブを保持し、空の理由を表示すること。グループ内検索と「すべて」での全体検索。
- 幅320pxでの一列表示・横方向のはみ出し、左右ボタン・ホイール操作、右端のMMDタブへの到達、右端での右ボタン無効化。
- 幅740pxへの変更に追従し、Inspector自体を横へはみ出させないこと。
- 選択タブ以外も全リセットされ、Undoで全グループの値と表示が復元されること。

Inspectorのスクリーンショットで、幅320pxでもタブのラベル、標準の選択状態、横スクロールバー、スライダーが見えることを確認しました。Light/Darkの切り替え自体はユーザー設定を維持するため行っていません。コンパイルエラーは0件、警告は他ツール由来の既存5件です。
