衣装の実ボーンとCloth Collider用オブジェクトの名前が似ている場合に、対応が曖昧としてコピーできなくなる問題を修正しました。

- Humanoid設定、SkinnedMeshRendererのボーン参照と親階層を使って実ボーンを判定します。
- コライダーなどの補助オブジェクトは階層を保ってコピーし、同名の実ボーンへの誤ったコピーを防止します。
- リグ情報のない階層では従来の名前照合を維持します。複数の実ボーン候補が残る場合は手動指定が必要です。

Unity 2022.3.22f1でSDKなし10項目、VRChat SDK 3.10.5あり12項目の検証が成功しました。コライダーの階層、Constraint/PhysBoneの参照置換、再コピー、Undoを確認しています。
