# Changelog

## 0.1.1 - 2026-09-27

- Humanoid設定を優先し、SkinnedMeshRendererのボーン参照と親階層を使って実ボーンを判定。
- 衣装の脚ボーンとCloth Collider用オブジェクトの名前が似ている場合に、対応が曖昧としてコピーできなくなる問題を修正。
- 補助オブジェクトは階層パスを保って対応付け、同名の実ボーンへの誤ったコピーを防止。
- リグ情報のない階層では従来の名前照合を維持。複数の実ボーン候補が残る場合は手動指定を要求。

## 0.1.0 - 2026-09-20

- Humanoid Alias Component Copierを独立したEditor専用VPMパッケージとして公開。
- ボーン辞書を同梱し、パッケージ内から自動読み込み。
- 共通ヘルパーはEditor Core 0.1.1以降に依存。
